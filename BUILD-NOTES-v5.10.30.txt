Reading MMO v5.10.30 — CrossInk BLE Phase 2 Session Import

- Keeps the SYNC READER control on the Home Reading panel.
- Uses Android/Chrome Web Bluetooth to discover Reading MMO Reader.
- Connects to service 7d2ea28a-f7bd-485a-bd9d-92ad6ecfe93e.
- Reads characteristic 7d2ea28b-f7bd-485a-bd9d-92ad6ecfe93e.
- Accepts Phase 2 payloads with sid, start page, end page, pages read, and reading seconds.
- Handles the Phase 2 no-session payload without changing app state.
- Previews a real reader session before the user chooses IMPORT SESSION.
- Imports exact reader pages and reading time through the existing Reading MMO session/quest accounting path.
- Updates current-book page/percent when the reader reports an end page.
- Refuses to merge into an already-active in-app reading session.
- Stores a session fingerprint so the same CrossInk session cannot be counted twice.
- Keeps Phase 1 test payload compatibility for older firmware during rollout.
- Keeps the visible app version locked to v5.10.30 while the v5.10.29 session-flow module is reused underneath.
- Uses internal cache generation 51030p2 so installed PWAs cannot reuse the older Phase 1 v5.10.30 BLE script.
